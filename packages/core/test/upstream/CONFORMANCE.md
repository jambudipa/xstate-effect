# Conformance ledger — xstate@5.33.2

This ledger records how the port conforms to `xstate@5.33.2` (decision D2). It lists every
upstream test file with its status, every gap row (S1–S27, A1–A23, C1–C22, P1–P14) with the test
that closes it, every upstream test the rewrites do not port, and every deliberate deviation.
The decisions it cites (D1–D20 and SD-1–SD-28) are in [docs/decisions.md](../../docs/decisions.md).

Rules:

- Checkers read the tables through `test/verify/ledger.ts`. Keep the section headings and the
  column headers exactly as they are. Write paths and names as plain text, with no backticks.
  Write a `|` inside a cell as `\|`. Write `—` for an empty describe path or a closing test
  that is not named yet.
- A status is one of `not started`, `rewritten`, `passes`, `deviation` (files) or `open`,
  `passes`, `deviation` (gap rows).
- Every deviation, removed and "Tests not ported" row cites the approved decision (D1–D20) or
  the spec decision (SD-1–SD-28) that requires it, both in `docs/decisions.md`, or a reason
  that only upstream can have, such as "skipped upstream". Difficulty, time or a failing
  implementation is never a reason.
- Scenario LEDGER-1 (`test/verify/verify-xstate-5-33-2-port-LEDGER-1.spec.ts`) checks this file.
